## Entry 2

### Sept 15 2026

During the class challenge, me, Angy and Konstantinos made a sunset lansdcape with a crow that appears when mouse is pressed. We had used p5.js before so for the most part, this challenge was really just a review of what we had learned before. We used a for loop to create a sunset gradient and a bunch of triangles and a quad to make the mountains. The entire bird was made in a single function and is made of circles (body and eyes) triangles (eyebrows and beak), ellipses (the angry circle near the beak), and lines (feet). The bird and a caw mp3 get called when mouse is pressed. As mentioned earlier, the 3 of us already worked on p5.js before so the challenge was mostly a review of things we had done in previous semesters in Dawson IMA. Personally, I never added sounds to my p5 projects so I did learn how to do that today. In some ways it is quite similar to how images are added to the README.md page so it wasn't complicated. The most challenging parts were the GiHub side of things. We had trouble getting the code to preview on the web and we also had trouble opening the project page.

For the most part, the prototyping instructions assignment was more of a review of codes I've used before. The first prototype I made was the one with the frog. Cuz I like frogs. This one's name is Johnny the Frog. It wasn't challenging to make, just time consuming. I don't enjoy making triangles in p5. This one went very well. I didn't come across any troubles while making it. I think it'd be fun if I added a function where the frog opens its mouth and ribbits when the mouse is clicked. The second prototype is the weird shapes thing I've titled Beats because it reminds me of those music visuals that react to sound. Except this one changes depending on mouse movement. I wanted to make something that was a bit more visually appealing for this one. This one was also mostly just a review of codes I've learnt before. The hard part of this prototype was making the file itself. I made this one on a separate day from the frog so I forgot how to start a file. I ended up copy pasting the frog file but that went horribly wrong and there were some issues where my computer was telling me I couldn't delete the misplaced files because I didn't have administrative permissions or something like that. In the end I just redownloaded the template file on Pippin's website and that worked great. The final prototype is a thing with black and white lines that kinda get cut at different points. For this one, I wanted to try a thing in p5.js I'd never used before. I stumbled across shearX and shearY. I wanted to test them out and ended up with this. I did a bit of experimenting with different shapes and parameters before arriving at the current final result. If I were to continue this prototype further, I'd try to include map in it to see if I can make the shear lines move in a smooth manner.
